# Changelog

## 0.1.0

- First release. Coding agents that wait for you, failed or finished appear in a pill at the macOS notch, which opens into cards. Click one to show its pane and bring your terminal forward.
- Claude Code's permission prompts and single questions, and Codex's command approvals, can be answered from a card; everything else can be opened. A command is shown in full (up to three lines) and `allow` is offered only when all of it is visible.
- Works with every agent cornercase reports, not only Claude Code.
